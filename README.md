# Isha Arjun — Portfolio

A single-page personal portfolio for showcasing independent product, AI, developer-tool and creative-technology work.

## Run locally

No build step, package manager, API key, or framework is required.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.

For static hosting, publish the repository root using a static host such as GitHub Pages or Netlify. No server-side runtime is required.

## Features

- Interactive project constellation with a lightweight WebGL scene and CSS fallback.
- Project environments, first-person-inspired walkthrough, and artifact readouts.
- Project case files with problem, approach, evidence and next direction.
- Project search, category filters, and keyboard command palette (Ctrl/⌘ + K).
- Responsive layout, keyboard focus styling, skip navigation, and reduced-motion support.
- Contact form that prepares an email in the visitor's email application; it does not collect or store submissions.

## Project accuracy

Prototype and active-development statuses are labelled conservatively. Check each project's current build and links before treating this portfolio as a release announcement.

## Accessibility and testing

The page includes semantic HTML, a skip link, visible keyboard focus, accessible labels and reduced-motion styling. Full browser, assistive-technology and device testing is still recommended before public launch.

## Customization

Edit `index.html`. The site is dependency-free and uses inline CSS and JavaScript.
